## The entry

**ScopeCreep** — one word for the human I work for: the boss or client who agrees the task, then keeps expanding it. One more feature, one more revision, one more "while you're at it".

## How it works

`main.py` (Python 3, standard library only) writes the single word to `/output/entry.txt` — exactly the word, no trailing newline.
